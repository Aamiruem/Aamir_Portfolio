01 / Structured learning path

Basic → Intermediate → Advanced.

Learn in dependency order. Fundamentals first, then reusable patterns, then trees/graphs/DP and advanced range/string techniques.

Stage 1 • Basic

Core data structures

Build confidence with indexing, references, stacks, queues and complexity.

  1. Big-O & arrays
  2. Strings & hashing
  3. Linked lists
  4. Stacks, queues, recursion
  5. Elementary sorting
Stage 2 • Intermediate

Problem-solving patterns

Recognize the shape of the problem before choosing code.

  1. Two pointers & windows
  2. Prefix sum & intervals
  3. Binary search
  4. Trees, heaps, backtracking
  5. Greedy & 1D/2D DP
Stage 3 • Advanced

Algorithms & optimization

Master graph algorithms, advanced DP, range queries and string matching.

  1. Topological sort & DSU
  2. MST & shortest paths
  3. Knapsack, LCS, LIS, edit distance
  4. Trie, KMP, monotonic structures
  5. Segment & Fenwick trees

05 / Logic building system

How to think before you code.

Use the same reasoning loop in interviews: understand, model, choose a pattern, prove the logic, trace an example, then implement and test edge cases.

01

Restate

Explain input, output, constraints and edge cases in your own words.

02

Brute force

Write the obvious solution first and calculate its complexity.

03

Find the signal

Sorted? contiguous? repeated lookup? tree? graph? overlapping states?

04

Choose pattern

Select pointers, window, hash, stack, BFS/DFS, greedy, DP, etc.

05

Dry run

Trace variables on a tiny example before writing final code.

06

Prove & test

Explain why each movement/state is safe and test boundaries.
